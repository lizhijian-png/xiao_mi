# 第二赛段：荒野寻珠 设计文档

## 一、赛道几何

### 坐标系约定

以第二赛段**入口虚线中点**为原点：
- **x**：向左为正（与第一赛段 x+ 方向一致，机器人左转后该轴指向左侧）
- **y**：向前（出口方向）为正
- 机器人从**右下角入口**进入，初始位置 x ≈ 3.1m，y = 0，朝向 90°（y+ 方向）

### 场地尺寸

| 参数 | 数值 |

| 场地长（y 方向） | 400cm |
| 黄色边沿宽 | 10cm（弯道 10cm） |
| 净宽通道 | 100cm |
| 球间距（行，y 方向） | 64cm |
| 球间距（列，x 方向） | 100cm |
| 球直径 | 20cm |
| 球底离地高度 | 20cm（球心约 30cm） |

### 球位坐标（估算，需现场校准）

列坐标（x，从右侧入口起算）：

| 列 | x 坐标 |
|----|--------|
| C4 | 0.60m  |
| C3 | 1.60m  |
| C2 | 2.60m  |
| C1 | 3.60m  |

行坐标（y，从入口虚线起算）：

| 行 | y 坐标 |
|----|--------|

出口虚线：y ≈ 3.20m，x ≈ 3.6m（左上角）

### 固定灰球（赛前确定，不可击）

- R4C3、R4C4、R3C4 固定为浅蓝色（不可击）

### 橙色球约束

每行每列各有且仅有 1 个橙色球（类数独）。由固定灰球推导：
- R4：橙球只能在 C1 或 C2
- R3：橙球只能在 C1、C2 或 C3
- R1、R2：无约束，C1~C4 均可

## 二、进出口与衔接

### 入口（来自第一赛段）

- 第一赛段末端机器人完成左转（0° → 90°），从弯道右侧进入第二赛段
- 入口位置：x ≈ 3.1m（场地右侧边），y = 0
- 进入时朝向：90°（y+ 方向，即正对球场纵深）

### 出口（前往第三赛段）

- 位置：左上角，x ≈ 3.6m（左侧），y ≥ 3.20m
- 赛段结束条件：后腿足底离开出口虚线
- 出口方向：继续 y+ 前进进入第三赛段 S 弯

## 三、解决策略

### 总体策略

**右侧入场 → 逐行扫描（从右向左）→ 视觉对准 → 撞击 → 左侧出场**

机器人沿 y+ 方向行进，每到一行的 y 坐标时停下，摄像头向前识别橙色球，平移对准后冲击，撞完后继续前进至下一行，最后向左平移至出口列，过虚线结束赛段。

### 行进路线

```
入口 (x≈3.1, y=0, 朝向90°)
  │
  ├─ 前进到 R4 (y≈0.64) ─→ 扫描 C4→C1 ─→ 找到橙球 ─→ 对准撞击
  │
  ├─ 前进到 R3 (y≈1.28) ─→ 扫描 ─→ 对准撞击
  │
  ├─ 前进到 R2 (y≈1.92) ─→ 扫描 ─→ 对准撞击
  │
  ├─ 前进到 R1 (y≈2.56) ─→ 扫描 ─→ 对准撞击
  │
  └─ 平移到 x≈3.6（左侧出口列）─→ 前进越过出口虚线 (y≥3.20)
```

扫描方向为**从右向左（x 减小方向）**，因为入口在右侧，机器人天然从 C4 侧开始，逐步向 C1 平移，路径最短。

## 四、状态机设计

```
ENTER_FIELD
  │  y 坐标进入球场范围（y > 0）
  ▼
GOTO_ROW4
  │  前进至 y ≈ 0.64m
  ▼
SCAN_ROW4  ──→ STRIKE_ROW4 ──→（撞击完成）
  │                                    │
  └────────────────────────────────────┘
  ▼
GOTO_ROW3
  │  前进至 y ≈ 1.28m
  ▼
SCAN_ROW3  ──→ STRIKE_ROW3 ──→（撞击完成）
  ...（R2、R1 同理）...
  ▼
GOTO_EXIT
  │  平移到出口 x，前进越过 y ≈ 3.20m
  ▼
DONE（返回 -1，切换赛段）
```

### 各状态说明

| 状态 | 动作 | 退出条件 |
|------|------|---------|
| GOTO_ROWn | 步态1前进 | y >= ROW_Y[n] |
| SCAN_ROWn | 步态7左移 + 摄像头识别 | 检测到橙色球在正前方（偏移 < 阈值） |
| STRIKE_ROWn | 步态1前进固定时间 → 步态6后退复位 | 计时完成 |
| GOTO_EXIT | 步态7左移到出口 x → 步态1前进 | y >= EXIT_Y |

## 五、视觉识别

### 橙色球检测函数 `detect_orange_ball(frame)`

```python
def detect_orange_ball(frame):
    """
    检测摄像头正前方是否有橙色球，返回横向偏移量。

    Returns:
        (found: bool, pixel_offset: float)
        found: 视野内是否有足够大的橙色区域
        pixel_offset: 球中心偏离图像中心的像素数（正=偏右，负=偏左）
    """
    h, w = frame.shape[:2]
    # 取图像中部区域（避免地面和天花板干扰）
    roi = frame[h // 4 : 3 * h // 4, :]

    hsv = cv2.cvtColor(roi, cv2.COLOR_BGR2HSV)
    # 橙色 HSV 范围（需根据现场灯光校准）
    lower_orange = np.array([10, 150, 100])
    upper_orange = np.array([25, 255, 255])
    mask = cv2.inRange(hsv, lower_orange, upper_orange)

    kernel = np.ones((5, 5), np.uint8)
    mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)
    mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel)

    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    contours = [c for c in contours if cv2.contourArea(c) > 500]  # 过滤噪点

    if not contours:
        return False, 0.0

    largest = max(contours, key=cv2.contourArea)
    M = cv2.moments(largest)
    if M["m00"] == 0:
        return False, 0.0

    cx = int(M["m10"] / M["m00"])
    return True, cx - w / 2  # 正=偏右，负=偏左
```

### 对准逻辑

| 像素偏移 | 动作 |
|---------|------|
| offset > +30px | 步态8（右平移） |
| offset < -30px | 步态7（左平移） |
| \|offset\| ≤ 30px | 对准完成，进入撞击 |
| 未检测到球 | 继续步态7左移扫描 |

## 六、撞击动作

| 阶段 | 步态 | 持续时间 | 说明 |
|------|------|---------|------|
| 冲击前进 | 1（vel=0.2）| ≈1.5s | 使机身正面接触球，令其晃动 |
| 后退复位 | 6（vel=-0.1）| ≈1.5s | 退回原行 y 坐标，为左移扫描让路 |

撞击距离估算：球心距通道中线约 0~50cm，前进 1.5s × 0.2m/s = 0.3m 足够覆盖最远情况。

## 十、风险与备选方案

| 风险 | 原因 | 备选方案 |
|------|------|---------|
| 橙球识别失败 | 灯光/阴影导致 HSV 不准 | 扫描整行后仍未找到，按约束推断位置（R4 只能在 C1/C2） |
| 撞击未使球晃动 | 偏移过大，刚好擦边 | 增大对准精度阈值到 15px，或增加冲击速度到 0.25m/s |
| 路径偏移累积 | 平移步态精度低 | 每行前进时增加朝向修正（保持 90°） |
| 出口找不到 | x 坐标偏差 | 到达 EXIT_Y 前不管 x，直接前进越线 |
