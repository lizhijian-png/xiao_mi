# 赛段4 规则改动与实现设计

> 本文档固化赛段4的新规则和已对齐的实现方案，作为写代码的依据。

## 一、规则改动（相对旧 segment4.py）

1. **三个目标物体随机摆放**：可乐、足球、橙色小球，分别随机放在左、中、右三条竖道上。
   - 每个物体恰好占一条道，三条道各一个物体（三物体的位置是 `{左,中,右}` 的一个排列）。

2. **限高杆 y 位置随机**：限高杆会在 **y=9.1 到 y=10.1** 范围内调整位置。
   - **只有左道和右道有限高杆**，中道没有限高杆。

3. **中道只能从随机的一侧进出**：
   - 中道四面被墙包住，**只有随机一侧**的墙面在 **y=8.6 到 y=9.1** 有一个开口。
   - 进中道和出中道，都必须从这个开口穿行。
   - 开口侧由输入参数指定：`0=左侧开口`，`1=右侧开口`。

## 二、输入参数（命令行）

启动命令格式（仿 segment2_manual.py）：

```
python3 segment4_manual.py <mid_open> <cola_pos> <football_pos> <orange_pos>
```

4 个整数，全部显式输入：

| 位置 | 参数 | 含义 | 取值 |
|---|---|---|---|
| argv[0] | mid_open | 中道开口侧 | 0=左，1=右 |
| argv[1] | cola_pos | 可乐所在道 | 1=左，2=中，3=右 |
| argv[2] | football_pos | 足球所在道 | 1=左，2=中，3=右 |
| argv[3] | orange_pos | 橙色小球所在道 | 1=左，2=中，3=右 |

- 例：`0 1 2 3` = 中道从左侧进出，可乐在左道，足球在中道，橙球在右道。
- 校验：4 个整数；mid_open ∈ {0,1}；三个 pos 必须是 {1,2,3} 的排列（互不相同），否则报错。

## 三、竖道访问顺序

- `mid_open = left` → **L → M → R → 桥**
- `mid_open = right` → **L → R → M → 桥**

（路径决定访问顺序，目标物不额外约束顺序。）

## 四、坐标与几何

沿用旧 segment4.py 的坐标系：

- `LEFT_LANE_X = -0.10`，`MID_LANE_X = 1.00`，`RIGHT_LANE_X = 2.10`
- 底部横向通道 `y = 7.10`（切换竖道走这里）
- 中道开口 `y ∈ [8.6, 9.1]`，进出点取 `y = 8.85`
- 入口起点 `(3.10, 7.10)`

## 五、限高杆处理（视觉探测 B 方案）

- 只在左道、右道触发低姿态；中道无限高杆，不蹲。
- 从 y=9.0 开始用视觉 `_detect_limit_bar_ahead` 检测红色横杆；一旦检出，进入低姿态（`LOW_BAR_GAIT`）。
- 低姿态区间覆盖 y=9.0 ~ 10.3（覆盖随机杆 9.1~10.1 并留余量）。
- Fallback：视觉一直没检出时，到 y=9.0 也强制进入低姿态，保证安全过杆。

## 六、每条竖道的通用动作流

每条道（除中道外的左右两道 + 中道）依次执行：

1. 从底部横道进入该竖道 x
2. 转向北
3. 对齐 x 中心线
4. 向北走（若有杆：过限高杆）
5. 走到目标物位置，播报（`识别到可乐瓶/足球/橙色小球`）
6. 撞击目标，后退指定距离
7. 转向南
8. 对齐 x 中心线
9. 向南走（若有杆：过限高杆）
10. 回到底部横道 y=7.10
11. 切换到下一条道

目标物撞击后退距离：

- 可乐：后退 0.15m
- 橙球：后退 0.20m
- 足球：后退 0.13m（过门）

## 七、中道进出（开口在 y=8.85）

进入：上一道（左道或右道）下行到 y=8.85 时，直接横穿开口进入中道，**不下到底部横道 y=7.10 折返**。

- `mid_open=left`（前一条左道，x=-0.10）：
  - 进入：左道下行到 y=8.85 → 向东横穿左侧开口 → 到中道中心线 (1.00, 8.85) → 转北。
  - 离开：中道撞完下到 y=8.85 → 向西横穿开口出到 (0.45, 8.85) → 转南 → 下到底部横道 y=7.10。
- `mid_open=right`（前一条右道，x=2.10）：
  - 进入：右道下行到 y=8.85 → 向西横穿右侧开口 → 到中道中心线 (1.00, 8.85) → 转北。
  - 离开：中道撞完下到 y=8.85 → 向东横穿开口出到 (1.55, 8.85) → 转南 → 下到底部横道 y=7.10。
