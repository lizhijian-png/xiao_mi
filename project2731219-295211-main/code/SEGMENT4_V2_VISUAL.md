小口位置推导:
  - 中道无杆，小口可以在左或右
  - 由 mid_open 参数决定 (0=左 0.35, 1=右 1.65)

  - 即中道右侧 (x ≈ 1.65)
  - 固定位置，mid_open 参数无效

规律总结
═══════════════════════════════════════════════════════════════════

小口位置规律:
  ┌─────────────┬──────────────┬────────────────┐
  │ 无杆道      │ 小口位置     │ 小口 x 坐标    │
  ├─────────────┼──────────────┼────────────────┤
  │ 左道 (1)    │ 中道左侧     │ 0.35 (固定)    │
  │ 中道 (2)    │ 由 mid_open  │ 0.35 或 1.65   │
  │ 右道 (3)    │ 中道右侧     │ 1.65 (固定)    │
  └─────────────┴──────────────┴────────────────┘

访问顺序规律:
  ┌─────────────┬──────────────┬────────────────────────┐
  │ 无杆道      │ mid_open     │ 访问顺序               │
  ├─────────────┼──────────────┼────────────────────────┤
  │ 左道 (1)    │ 任意         │ L(小口) → M → R        │
  │ 中道 (2)    │ 0 (左)       │ L → M(小口左) → R      │
  │ 中道 (2)    │ 1 (右)       │ L → R → M(小口右)      │
  │ 右道 (3)    │ 任意         │ L → M → R(小口)        │
  └─────────────┴──────────────┴────────────────────────┘

蹲姿需求:
  ┌─────────────┬──────────────────────────────┐
  │ 道路类型    │ 蹲姿需求                     │
  ├─────────────┼──────────────────────────────┤
  │ 有杆道      │ y ∈ [9.0, 10.3] 区间蹲姿过杆 │
  │ 无杆道      │ 无蹲姿，y=8.85 横穿小口      │
  └─────────────┴──────────────────────────────┘

═══════════════════════════════════════════════════════════════════
关键实现差异
═══════════════════════════════════════════════════════════════════

有杆道流程:
  进入竖道 → 转北 → 对齐
  → y=9.0 开始蹲姿 → y=10.3 站起
  → 撞目标 → 后退 → 转南 → 对齐
  → y=10.3 开始蹲姿 → y=9.0 站起
  → 返回底部横道

无杆道流程:
  走到 y=8.85 → 横穿小口进入 → 转北 → 对齐
  → 向北到目标（无蹲姿）
  → 撞目标 → 后退 → 转南 → 对齐
  → 向南到 y=8.85 → 横穿小口出去
  → 继续向南到底部横道

足球特殊处理:
  有杆道足球: 撞击后保持低姿态短退 → 低姿态返回过杆
  无杆道足球: 撞击后正常后退（无需蹲姿）
