# 赛段6「撷金建功」带球—踢球—趴下 集成设计文档

**日期**：2026-05-30
**状态**：待审阅（横移方案废弃后重做）

---

## 目标

重做赛段6「撷金建功」控制逻辑：机器狗从赛段5跳下的落点出发，把足球 C
带到终点圈，在圈内把球踢出去，然后回到圈内趴下完成全程。

**为什么推翻旧方案**：旧 `segment6.py` 走「先把球向 −y 推、再向 +x 推」的
L 形正交路径，要求狗先站到球**正上方**那条只有 50cm 的窄缝里横移就位。
实测横移太慢/几乎不走——根因不是步态参数，而是**几何上塞不进去**：球顶到
独木桥只剩 50cm，狗身长约 0.7m，竖着摆不进、也没法在缝里转身。任何正交
方向（正上 / 正左）就位都撞同一堵墙。必须换一种几何可行的姿态。

---

## 方案选择：对角线带球（思路一）

采用**里程计主控 + 视觉钩子预留 + 对角线推球**。

- **主控走纯里程计**（position x/y + rpy 朝向），确定性强、与赛段1–5
  状态机结构一致，不被感知调参卡住。
- **保留 `detect_ball(frame)` 视觉钩子**并接入控制流，默认 `frame=None`
  关闭；现场可在「墙角入位」这一最易偏的环节开启视觉纠偏，**无需改控制
  函数签名**（与赛段1 `detect_yellow_line_offset` 处理方式一致）。
- **踢球用脚本化快速步态**（复用 step28 快前进的思路）。
- **路径改为单一对角线方向**：狗斜站在球的左上方、机头朝右下 ~328°，
  把球朝右下（直奔终点缺口）推出，分「首推出角 → 开阔区带球」两段完成。

被否决的另两个思路（留档）：
- **思路二「先顶出墙角再正交推」**：只第一下用短对角线把球顶出角落，
  之后改正交推。本设计已把它的优点（先脱角）吸收为阶段C「首推出角」，
  不再单列。
- **思路三「对角线一脚踢射进圈」**：墙角停留最短，但纯开环、落点全靠瞄，
  偏一点就出界/卡墙，最不可控，否决。仅作踢球退路保留（见风险章）。

## 坐标系约定（与赛段1–5一致）

原点 (0,0) 在第一赛段中轴线上，距左侧黄线 0.6m、距下侧黄线 0.5m。

| 轴 | 方向 | 朝向角 |
|----|------|--------|
| x  | 水平向右为正 | 0° |
| y  | 竖直向上为正 | 90° |
| −x | 水平向左 | 180° |
| −y | 竖直向下 | 270° |
| rpy[2] | 机身朝向角（°），由 odometry 给出 | — |

右下对角线（球 → 终点圈方向）≈ **328°**（机头朝右下偏下约 32°）。

## 场地事实（已与用户确认）

| 要素 | 数值 | 说明 |
|------|------|------|
| 可行驶矩形 | x∈[−0.10, 2.90]，y∈[12.60, 15.10] | 3.0m×2.5m，边界可触碰不可越出 |
| 起点（独立摆位） | ≈(2.5, 13.5)，朝向 180° | 赛段5跳下落点，面向 −x（球方向） |
| 足球 C 中心 | (0.50, 14.50)，半径 0.10 | 左缘 x=0.40，上缘 y=14.60 |
| 独木桥（唯一障碍） | 仅占**左上角**一小块 | 球左/上各距桥 50cm；**球的左下方为开阔地** |
| 终点缺口 | x=2.90，y∈[12.60, 13.10] | 右下角唯一可通过的 50cm 开口 |
| 终点圈 | 圆心≈(3.15, 12.85)，半径 0.25 | 直径 50cm「刚好容四脚」，狗身中心须贴圈心 |

**关键前提（思路一成立的依据）**：独木桥只堵住球的左上角，球的**左方/
左下方是开阔地**，狗可从左下方绕到球的左上侧就位。若现场发现左边界是从
下贯到上的整堵硬墙、左下方不开阔，则思路一的「绕到墙侧」不成立，须退回
踢球方案（见风险章）。

## 核心几何洞察（本段成败的关键）

球被独木桥堵在左上角，左、上各仅 50cm。要把球推向右下的终点缺口，
**接触点必须在球的左上半球**（从开阔的东/南侧接触只会把球推得更进角）。

- **正交就位（旧方案）**：站到球正上方 → 需挤进 50cm 上缝（狗身 0.7m
  竖放塞不进）；站到球正左方 → 需挤进 50cm 左缝（狗身横放塞不进）。
  **两条正交路都被墙堵死，这就是横移失败的真因。**
- **对角线就位（本方案）**：狗斜放、机头朝右下 ~328°，身体沿 45° 对角线
  伸进左上墙角。墙角沿 45° 方向的可用长度 ≈ 0.5/cos45° ≈ **0.7m**，
  恰好容下狗身——这是唯一塞得进墙角的姿态。
- **方向是白送的**：从球 (0.5,14.5) 朝终点圆心 (3.15,12.85) 拉直线，
  斜率 −0.62，过缺口 x=2.90 时 y≈13.0，正落在缺口 [12.6,13.1] 内。
  所以「对准缺口推」的方向天然 ≈328°，一推到底就穿缝进圈。

**诚实说明（必须写进设计）**：墙角只容得下推球这一个静态位姿（PRE_PUSH≈
(0.20,14.69)，后右角距左墙仅1cm、界内），**无余量在角里原地转身**（扫掠半径
0.29m > 球距0.25m，会扫球）。因此入位必须「开阔区转好328° → 朝左上倒退进角」：
用后退步态(idx26/6)贴墙倒进去，**左墙/顶墙当挡块自对正**（墙可触碰）。
残余风险只剩一处——倒退途中机身侧缘从球旁约1~2cm掠过，会否蹭球需仿真确定；
故「转身+倒退进角 + 起步首推」(阶段B/C)定为**全段唯一高风险环节**，配视觉
纠偏 + 踢球退路（见风险章）。阶段C一旦把球顶离墙角，左/上空间全开，
后续全在开阔区，里程计闭环即可稳控。

## 分阶段路径与航点（里程计驱动，狗机身中心目标值）

| 阶段 | 名称 | 起点→目标 | 朝向 | 主步态 | 退出条件 |
|------|------|-----------|------|--------|----------|
| A | 接近·到转身点 | (2.5,13.5) → 球右下方开阔转身点 TURN_PT≈(0.88,14.27) | 移动中 | 导航前进/转向 | 到达 TURN_PT（离球0.44m，不接触球） |
| B | 转身+倒退进角★ | TURN_PT 转到328° → 朝左上(148°)倒退进 PRE_PUSH≈(0.20,14.69) | 转到328°后保持 | 转向→后退(26/6) | 到 PRE_PUSH（前缘贴球左上缘） |
| C | 首推出角★ | 朝328°推，球从墙角带到开阔区 ≈球(1.1,14.0) | 保持 328° | 低重心推球(43) | 球(估计)离墙角 / 狗到中段 x |
| D | 开阔区带球 | 循环「对准328°→前推」把球带到缺口前 | 保持 328° | 低重心推球(43) | 狗到 x≈2.4（球临近缺口） |
| E | 穿缝进圈 | 换快速步态把球送过 x=2.90，狗随球进圈 | 保持 328° | 快前进(28) | 狗中心到 x≈3.15（圈心） |
| F | 圈内趴下 | 终点圈内趴下，计时停止 | — | 趴下(4) | 趴稳，返回 −1 |

★ = 高风险窄缝环节（B、C），视觉钩子 / 现场调参重点。

**入位机制（核心，纠正旧版「沿左墙上行」的错误）**：墙角只够塞下推球这**一个**
静态位姿（PRE_PUSH），几乎无余量原地转身或绕行。两条几何事实定死了入位方式：

1. **不能在墙角转身**：在 PRE_PUSH 原地转身扫掠半径≈0.29m，而球面最近点距狗心
   只 0.25m → 会扫到球。**必须在开阔区先转好 328°，再平移进角。**
2. **进角方向=后退方向**：328° 朝向下，从开阔区进墙角需朝 **148°（左上）** 移动，
   恰是机身正后方。故用**后退步态**(idx 26 vx−0.20 / idx 6 vx−0.10)倒退进角，
   **左墙(x=−0.10)与顶墙(y=15.10)正好当挡块**自对正——墙可触碰，贴墙即到位。

所以阶段A把狗带到球**右下方**的开阔转身点 TURN_PT≈(0.88,14.27)（离球心0.44m，
转身扫掠不碰球；且在球的「右下出球侧」，不会先把球顶回角）；阶段B在此转到328°
后**朝左上倒退**贴进 PRE_PUSH，前缘正中贴上球左上缘，一推即沿对角线奔缺口。

> **残余风险（诚实说明）**：倒退进角那段，机身侧缘从球旁约1~2cm掠过，会否蹭球
> 只能由仿真确定。这正是预留 `detect_ball` 视觉钩子 + 踢球退路的那个点——
> 风险真实，但属「做得出、需仿真调」，非「做不出」。

**航点常量（绝对坐标，米；现场可微调）**：

```
START          ≈ (2.50, 13.50)   # 赛段5落点，朝180°
APPROACH_LD    ≈ (0.00, 13.70)   # A：球左下方绕行预备点（开阔地，离左墙0.1m，不接触球）
PRE_PUSH       ≈ (0.20, 14.69)   # B/C 终点：推球位姿，机头328°，前缘正中贴球左上缘(0.415,14.553)
                                 #   后右角≈(-0.089,14.69) 距左墙(-0.10)仅1cm（界内）；只前缘一点碰球
TURN_PT        ≈ (0.88, 14.27)   # B 起点：球右下方开阔转身点（离球心0.44m>0.39m，转身扫掠不碰球）
HEADING_PUSH   = 328             # 推球朝向：球→终点圈方向（atan2(-1.65,2.65)）
BALL0          = (0.50, 14.50)   # 球初始中心
DRIBBLE_LINE   : 过BALL0、斜率-0.62 的直线 y = 14.50 - 0.62*(x-0.50)
KICK_TRIGGER_X = 2.40            # D→E：狗到此 x 改快速步态
GAP_X          = 2.90            # 缺口边界
FINISH_CX      = 3.15            # 圈心 x（狗最终停靠）
FINISH_CY      = 12.85           # 圈心 y
FINISH_R       = 0.25
XY_TOL         = 0.08            # 航点到达容差
HDG_TOL_SLOW   = 8               # 朝向慢调阈值（°）
HDG_TOL_FAST   = 20              # 朝向快调阈值（°）
```

**带球方向控制（阶段C/D 核心）**：本段不做横向纠偏，而是**始终把机身朝向
对准 328°**。只要朝向锁定，狗沿机头方向直推，球被机身/前腿带着沿对角线滚向
缺口。朝向漂移时先用转向步态拉回 328° 再推（与赛段5 `_walk` 同构：先对朝向、
对准后才前进）。这样把「带球到缺口」化简为「锁朝向 + 直推」，无需逐航点闭环。

## 状态机

```
A_APPROACH      接近：导航到球右下方开阔转身点 TURN_PT≈(0.88,14.27)（不接触球）
B_BACK_IN       转身+倒退进角★：在 TURN_PT 转到328°→朝左上(148°)后退步态贴进 PRE_PUSH≈(0.20,14.69)，墙作挡块自对正
C_PUSH_OUT      首推出角★：朝 328° 低重心推，把球带离墙角到开阔区
D_DRIBBLE       开阔区带球：锁 328° 直推，把球带到缺口前（狗到 x≈2.4）
E_THROUGH_GAP   穿缝进圈：换快前进把球送过 x=2.90，狗随球到圈心 x≈3.15
F_LAYDOWN       圈内趴下，计 3 帧后置 DONE
DONE            返回 -1
```

状态转移与赛段5同构：每帧读 `position/gait_mode/rpy`，
`(gait==0&&mode==0)||(gait==1&&mode==9)||mode==7` 时返回 0 等待动作完成，
避免重复发指令打断步态。

## 视觉钩子（预留，默认关闭）

`detect_ball(frame)`：识别相机帧中足球，返回球相对机身的**横向偏移**
（像素，正=偏右），用于阶段 B/C 在墙角窄缝里纠正狗相对球的对位。

- 默认主控传 `frame=None`，函数直接返回 0.0，控制走纯里程计——确定性优先。
- 现场若发现墙角入位/首推总是偏，可接入 HSV+圆检测返回真实偏移，由 B/C
  状态据此左右微调，**不改 `segment6_control` 签名**（与赛段1
  `detect_yellow_line_offset` 一致）。

## 错误处理与边界

- **越界保护**：阶段 A/B 的就位点贴左墙（x≈0.0，本体左缘≈−0.1 刚到墙线），
  靠航点常量约束，不主动贴墙；若 odometry 显示已触 x≤−0.10 或 y≥15.10，
  当前移动步态退化为站立等待人工/视觉介入，不强行顶墙。
- **朝向漂移**：所有推球阶段先对朝向后前进，漂移超 `HDG_TOL_SLOW` 即纠回。
- **球未被带走（推空）**：纯里程计无法直接感知；阶段 D 设里程上限，
  狗到 KICK_TRIGGER_X 仍按计划进入 E，由快速步态补推/踢；若现场开视觉，
  可用 `detect_ball` 判断球是否仍在身前。
- **狗未完全进圈**：阶段 E 不留 −XY_TOL 余量，要求狗中心到达 FINISH_CX，
  确保后脚也越过缺口 x=2.90 落进圈内（圈仅50cm，零余量）。
- **趴下打断**：F 阶段 `mode==7` 时返回 0 等待，趴稳计 3 帧再置 DONE。

## 风险与退路

| 风险 | 触发 | 退路 |
|------|------|------|
| 墙角入位塞不进（左下方其实不开阔/左墙整堵） | 阶段B无法到 328°位、反复触墙 | **改踢球方案**：狗在墙角外沿328°对准缺口，用 G_KICK 一脚把球打向缺口，再追球收尾（思路三） |
| 首推把球推进角而非出角 | 接触点偏到球右/下侧 | 开视觉钩子校正接触侧；或阶段A就位点再往左下挪 |
| 带球途中球偏离对角线 | 朝向漂移 / 地面不平 | 锁朝向纠偏；开视觉补横向偏移 |
| 球卡缺口边沿不进圈 | 球速不足/对位偏 | 阶段E快前进补推；必要时狗进圈后回身轻顶 |

**首要退路是踢球**：若现场反复验证「绕到球墙侧」几何不可行，整段降级为
「墙角外对准缺口 → 快速步态踢射 → 追球 → 圈内趴下」，复用同一套朝向/步态/
状态机骨架，仅去掉 B/C/D 的推球循环。

## 测试

无单元测试惯例的硬件/仿真项目，沿用赛段5的 `if __name__=="__main__"`
独立入口：起 LCM、`Robot_Ctrl`、`Pos_msg`、`Gait_msg` 三线程，逐帧调
`segment6_control` 并打印 `pos/yaw/step/state`，`step==0` 时 sleep 4s
等动作完成，`step==-1` 退出并发趴下兜底。

验证顺序（现场）：① 先跑阶段A/B 看能否进 328°墙角位（最高风险，先单独验）；
② 验阶段C 首推能否把球带离墙角；③ 验 D/E 带球穿缝进圈；④ 全程串跑 + F 趴下。
每步先纯里程计，偏了再开 `detect_ball` 视觉纠偏。
