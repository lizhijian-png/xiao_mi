# 赛段6「撷金建功」角落转身—低重心横移顶球—转身前推 设计文档

**日期**：2026-05-31
**状态**：已实现并修订（见下「修订2」）

---

## 修订2（2026-05-31）：D 段拆为三段式 + 加深重心

仿真发现两个问题，据此修订 C/D 段（其余 A/B、E→H、踢球退路不变）：

1. **重心不够低，球从身下穿过**：原横移步态 `pos_des z=-0.08` 压得不够，横移时球从机身下漏过。→ 把左横移步态(gait 44)的 `pos_des z` 加深到 **−0.12**。
2. **横移后直接转身碰球**：左扫把球顶出后，狗与球贴得近，原地转 328° 会蹭球。→ D 段拆成两段：先左扫顶球，再向右退开拉间隙，再转身。

**修订后 D 段（三段式，全程低重心不抬身）**：

| 阶段 | 状态 | 步态 | 退出 |
|------|------|------|------|
| D1 左扫 | `_ST_D1_SWEEP` | 低重心**左**移 gait 44（z=−0.12, vel_y=+0.08） | 里程位移 ≥ `SWEEP_L_DIST`=**0.25m** → 置 D2，起点清回 None |
| D2 右退 | `_ST_D2_CLEAR`（新增） | 低重心**右**移 gait 45（z=−0.12, vel_y=−0.10，新增） | 里程位移 ≥ `SWEEP_R_DIST`=**0.15m** → 置 E，发 G_STAND |

**起点变量复用**：D1/D2 共用 `_sweep_x0/_sweep_y0`。D1 首帧记起点；D1 退出时清回 None；D2 首帧重记起点。reset 仍只需清 None。

**常量改名/新增**：`G_SWEEP`→`G_SWEEP_L`(44)、新增 `G_SWEEP_R`(45)；`SWEEP_DIST`→`SWEEP_L_DIST`(0.25)、新增 `SWEEP_R_DIST`(0.15)。`HDG_SWEEP=225` 不变。

**几何复核**：头 225° 时狗左侧朝世界 315°（东南，对球）。D1 左移(机身+y)把球往东南顶出角落；D2 右移(机身−y，朝西北)狗退离球、拉 0.15m 间隙，仍在边界 x∈[0,2.8]/y∈[12.7,15.0] 内不撞墙；E 原地转 328° 此时不碰球，狗落在球后方正对缺口；F/G 沿 328° 直推。

**诚实风险**：横移四腿迈步、腿间有缝，−0.12 未必100%堵住球，最终深度靠仿真定（做得出、需调参）；保留 `detect_ball` 视觉钩子兜底。

> 以下原始章节描述的是修订前的「D 单段左扫 0.20m」方案，保留作演进记录；实现以本「修订2」为准。

## 目标

修订赛段6「撷金建功」的角落机动逻辑。机器狗从赛段5落点出发，把足球带过右下
缺口送进终点圈、四脚进圈趴下、计时停止。整体框架（贴墙到角自定位 → 转身前推
护球进缺口 → 趴下）不变，**只替换原 C/D 两阶段**（头朝148°、后退步态倒顶）。

**为什么再次修订**：现场得知第六赛道**内侧有一圈黄线**，赛道实际边界收紧为
**X∈[0.0, 2.8]、Y∈[12.7, 15.0]**。这导致机器狗走到左上角后**空间不足**，无法
按原方案让后体转向 328° 倒退顶球——倒退时会把球推走/顶歪，几何上塞不下这个
动作。

**新思路（本设计）**：到左上角后**不再倒退**，改为**原地转身 + 低重心横移**把球
顶出来：
1. 到角后原地转头**逆时针到约 225°**（头朝左下方）；
2. **切换成低重心步态**，向左**横移约 20cm**；此时狗的左侧身体扫过球，把球顶向
   右下开阔区；
3. 之后与原策略一致：转身让头朝 328° 正对球 → 低重心前推护球穿缝进圈 → 趴下。

横移是**平移**而非倒退，不要求后体精确摆进球旁狭小位姿，在收紧的边界内可行；
低重心压低机身确保侧身/腿能接触到球。

## 方案选择

对比三个「到角后把球顶出」的执行变体（均基于已验证的「贴墙到角」自定位前提）：

- **变体一「转身 + 低重心横移顶球」（本设计采用）**：到角转头到 225° → 低重心
  左横移 20cm 把球扫出角落 → 转身正对球前推。横移是平移、距离闭环（里程位移
  ≥0.20m 退出），在收紧边界内空间够；低重心保证接触球。**最契合新边界约束**。
- **变体二「原 C/D 倒退顶球」（已否决）**：到角转尾朝 328° 后退顶球。在旧宽边界
  （x 到 2.9、y 到 15.1）下可行，但新黄线边界收紧后角落空间不足，后退会把球
  推走/顶歪，几何塞不下，**因此被本设计替换**。
- **变体三「贴左墙下行绕到球后」（否决）**：到角后沿左墙下行到球左下方直接转
  328° 前推。绕到球后方就位仍易蹭球（球贴角），是旧方案未解决的难点，否决。

首要退路仍是踢球方案（`USE_KICK_FALLBACK`，见风险章），该退路本就跳过 C/D，
不受本次改动影响。

## 核心几何（本方案成立的依据）

**① 328° 直线天然穿缝直达圈心（推球段几何免算，与上一版一致）**

从球 (0.5, 14.5) 朝终点圈心 (3.15, 12.85)：方向 = atan2(−1.65, 2.65) ≈ −31.9° →
**328.1°**。沿此线 y = 14.50 − 0.622·(x−0.50)：到缺口 x=2.80 时 y ≈ **13.07**，落在
缺口 [12.70, 13.10] 内 ✓；到圈心 x=3.15 时 y ≈ **12.85** ✓。锁 328° 直推，球与狗都
沿这条线进圈。

**② 贴墙到角自定位（替代精确摆位，与上一版一致）**

A 段贴右墙上行、B 段贴顶墙左行，到左上角时 x 被左墙(0.0)、y 被顶墙(15.0)钉死，
狗位置由两墙确定，不依赖精确里程计。狗中心走在 y ≈ 14.85（距顶墙 0.15m），机身
下缘 y ≈ 14.70 > 球上缘 14.60，从球上方约 0.1m 掠过不碰球（新边界下余量收紧到
约 0.1m，仍清空）。

**③ 转身 225° + 低重心左横移顶球（C/D 核心，本次新写）**

到角后狗从 180° 逆时针转到头朝 **225°**（左下方）。此姿态下狗的**左侧身体**朝向
世界 **~315°（右下方）**——正是球相对狗所在的方向。向**左横移（机身 +y）**即让
左侧身体扫过球 (0.5,14.5)，把球沿右下方顶出角落，朝 328° 推球起始区送。横移是
**平移**，不要求精确摆位；**低重心**（机身下压 0.08m）保证侧身/腿能接触到球。

横移约 **20cm** 后停（里程位移闭环判退出）。横移朝右下方远离左墙(0.0)、顶墙(15.0)，
方向天然安全，不会越界。

**残余风险（诚实说明）**：横移侧身能否干净顶到球、顶出方向是否够接近 328° 推球
起始区，只能靠仿真确定——属「做得出、需调参」。保留 `detect_ball` 视觉钩子 +
踢球退路兜底。球一旦被顶离角落、狗转身对准 328°，后续全在开阔区沿已验证的
328° 直线推进。

## 状态机

```
A_GO_TOP        上行：转90°贴右墙向上，到 y≥14.80
B_GO_CORNER     左行：转180°贴顶墙向左到左上角，到 x≤0.20（左墙挡停，自定位）
C_AIM_SWEEP★    转身：从180°逆时针转到头朝225°（左侧身体朝右下对球）
D_SWEEP★        低重心横移顶球：进D首帧记起点，发低重心左移(44)，里程位移≥SWEEP_DIST退出
E_FACE_PUSH     转身：原地转头到328°正对被顶出的球
F_DRIBBLE       带球：锁328°低重心前推(43)，把球带到缺口前（狗到 x≥2.40）
G_THROUGH_GAP   穿缝：保持低重心推(43)送球过 x=2.80，狗随球到圈心 x≥3.15
TURN_FINISH     圈内原地转身，头从328°转到正对+x(0°)
H_LAYDOWN       圈内趴下，计3帧后置 DONE
DONE            返回 -1
```

**新增状态变量**：`_sweep_x0, _sweep_y0`（横移起点里程），`reset_segment6()` 置 None；
进 D 首帧（仍为 None 时）记录当前 (x,y)。新增纯函数 `_dist(x,y,x0,y0)` 算欧氏位移，
便于单测。

**新增纯辅助函数**：
```
_dist(x, y, x0, y0) -> float    # sqrt((x-x0)^2+(y-y0)^2)，横移位移判据
```

状态转移与赛段5同构：每帧读 `position/gait_mode/rpy`，
`(gait==0&&mode==0)||(gait==1&&mode==9)||mode==7` 时返回 0 等待动作完成。
**H_LAYDOWN / DONE 例外**（与上一版一致）：H 让趴下帧计数确定性推进到 DONE；
DONE 须无条件返回 −1。

**C/D 控制逻辑（伪码）**：
```
elif _state == _ST_C_AIM_SWEEP:
    ts = _turn_step(rpy, HDG_SWEEP)        # 转到225°
    if ts != 0: return ts
    _state = _ST_D_SWEEP
    return G_SWEEP                          # 对准后进 D，首发横移

elif _state == _ST_D_SWEEP:
    if _sweep_x0 is None:                   # 进 D 首帧记起点
        _sweep_x0, _sweep_y0 = x, y
    if _dist(x, y, _sweep_x0, _sweep_y0) >= SWEEP_DIST:
        _state = _ST_E_FACE_PUSH
        return G_STAND
    ts = _turn_step(rpy, HDG_SWEEP)         # 漂移先转回225°再横移
    if ts != 0: return ts
    return G_SWEEP
```

## 错误处理与边界

- **越界保护**：新边界 x∈[0.0,2.8]、y∈[12.7,15.0]。A/B 靠航点阈值（y≥14.80 /
  x≤0.20）停，不主动顶墙；若 odometry 显示触界，当前移动步态退化为站立等待。
- **横移方向安全**：D 段向左横移（机身+y，世界~315°右下方），远离左墙(0.0)、
  顶墙(15.0)，不会越界。
- **横移起点未记录兜底**：进 D 首帧若 `_sweep_x0 is None` 当帧先记录再发步态，
  避免位移判据用到脏值。
- **朝向漂移**：C/D/E 沿用 `_walk` 同构——偏差超 8° 慢转、超 20° 快转，对准后才
  横移/前进。
- **D 段顶球失败兜底**：纯里程计不直接感知球。D 设位移上限 SWEEP_DIST 必退出，
  靠 E 转身 + F 前推补救；现场可开 `detect_ball`。
- **狗未完全进圈**：G 段不留余量，要求狗中心到 FINISH_CX=3.15，确保后脚越过缺口
  x=2.80 进圈。
