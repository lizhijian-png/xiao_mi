# 赛段6「撷金建功」角落倒顶—转身前推—趴下 设计文档

**日期**：2026-05-31
**状态**：待审阅（「对角线带球 + 倒退进角」方案实测不可行后重做）

---

## 目标

重做赛段6「撷金建功」控制逻辑：机器狗从赛段5跳下的落点出发，把足球 C
带过右下缺口送进终点圈，然后机器狗四脚进圈、趴下，计时停止。

**为什么再次推翻**：上一版「对角线带球 + 倒退进角」要求狗在球的**右下开阔点**
转好 328° 后，朝左上（148°）**斜向倒退贴进墙角**到一个后右角距左墙仅 1cm 的
精确位姿（PRE_PUSH）。实测这条斜向倒退进角的轨迹无法稳定落到那个零余量位姿
——倒退方向稍偏就蹭球或顶墙卡死，几何上塞不进去。根因和最早的窄缝横移一样：
**任何要求狗精确摆进球旁狭小位姿的入位方式都做不出来。**

**新思路（本设计）**：不再要求精确摆位，改用**两面墙当导轨自定位**。狗先贴顶墙、
再贴左墙走到**左上角**，到角时 x、y 被两墙钉死，自然定位。到角后让**头扎进角
(148°)、尾朝开阔的右下(328°)**，用后退步态让后体倒退把球从角里**顺一下**顶出来；
再原地转身 180° 让头朝 328° 正对球，用前推步态把球护送过缺口、进圈、趴下。

**头进角、尾顶球**——这正是关键。旧方案都栽在「头必须挤进窄角对准球」这个做不出
的姿态上；本方案反过来，让头占据空旷的墙角（角里无球，不需对准精度），用尾去
顶球，姿态天然可行；到角又靠撞两面墙自定位，不依赖精确里程计。

---

## 方案选择

对比三个执行变体（均基于「贴墙到角」的自定位前提）：

- **变体一「角落倒顶 + 转身前推」（本设计采用）**：贴墙到角 → 转尾对准 → 倒退顺球
  出角 → 转身 180° → 前推护球进缺口。倒退只负责把球从角里顺出来，精确护送交给
  转身后的前推段（该段几何已验证）。**最稳**：到角自定位、头朝空角不需精度、
  护送段复用已验证逻辑。
- **变体二「贴墙下行直接前推」**：到角后不倒顶，改沿左墙下行到球的左下方，直接转
  328° 从头开始前推。省掉倒顶 + 转身，但「绕到球后方再对准」仍是旧方案没解决的
  难点（球贴角，左下方就位仍易蹭球），否决。
- **变体三「全程倒退推到底」**：到角转尾后一直倒退把球推到缺口外，不转身。控制最
  简（单阶段），但长距离倒退带球稳定性差、球易跑偏轴、看不见前方缺口，否决。

被否决的两个变体留档备查；首要退路仍是踢球方案（见风险章）。

## 核心几何（本方案成立的依据）

**① 328° 直线天然穿缝直达圈心（推球段几何免算）**

从球 (0.5, 14.5) 朝终点圈心 (3.15, 12.85) 拉直线：
方向 = atan2(12.85−14.50, 3.15−0.50) = atan2(−1.65, 2.65) ≈ −31.9° → **328.1°**。
沿此线 y = 14.50 − 0.622·(x−0.50)：

- 到缺口 x=2.90 时 y ≈ **13.01**，正落在缺口 [12.60, 13.10] 内 ✓
- 到圈心 x=3.15 时 y ≈ **12.86**，正是圈心 (3.15, 12.85) ✓

**这条 328° 直线从推球起点一路穿过缺口直达圈心**——只要锁住 328° 朝向直推，
球与狗都沿这条线进圈。推球段（F/G）的几何因此天然成立，与上一版一致、已验证。

**② 贴墙到角自定位（替代精确摆位）**

狗中心贴顶墙走在 y ≈ 14.95（距顶墙 0.15m），机身下缘 y ≈ 14.80 > 球上缘 14.60，
**从球上方约 0.2m 掠过，不碰球**。到左上角时，左墙(x=−0.10)钉住 x、顶墙(y=15.10)
钉住 y，狗位置由两墙确定，无需精确里程计——这是本方案比「摆进狭缝」鲁棒的根本。

**③ 头进角、尾顶球（姿态天然可行）**

到角后狗转到**头朝 148°（左上、扎进空角）、尾朝 328°（右下、对准缺口方向）**。
后退步态 = 朝尾方向(328°)平移，狗后体朝右下扫过球 (0.5,14.5)，把球沿 328° 顺出
角落。角里无球，头朝角不需对准精度；用尾顶球，避开「头扎窄角对准球」的死局。

**残余风险（诚实说明）**：D 段后体倒退能否干净顶到球、顶出方向是否够接近 328°，
只能靠仿真确定——和旧方案一样属「做得出、需调参」，非「做不出」。这一处保留
`detect_ball` 视觉钩子 + 踢球退路兜底。一旦球被顶离角落、狗转身对准 328°，
后续全在开阔区沿已验证的 328° 直线推进，里程计闭环即可稳控。

## 分阶段路径与航点（里程计驱动，狗机身中心目标值）

| 阶段 | 名称 | 动作 | 朝向 | 主步态 | 退出条件 |
|------|------|------|------|--------|----------|
| A | GO_TOP | 上行贴顶墙 | 90° | 转向→前进(1) | y≥14.85（贴顶墙） |
| B | GO_CORNER | 沿顶墙左行到左上角 | 180° | 转向→前进(1) | x≤0.20（左墙挡停） |
| C | AIM_TAIL | 转尾对准328°（头转到148°） | →148° | 慢/快转(2/3,14/15) | 头对准 148° |
| D | NUDGE | 倒退顺球出角 | 保持148° | 后退(26) | x≥0.35（后体扫过球） |
| E | FACE_PUSH | 原地转身头朝328° | →328° | 转向(180°大转) | 头对准 328° |
| F | DRIBBLE | 锁328°前推带球到缺口前 | 保持328° | 推球(43) | x≥2.40 |
| G | THROUGH_GAP | 快步态送球穿缝、狗随球进圈 | 保持328° | 快前进(28) | x≥3.15（圈心） |
| H | LAYDOWN | 圈内趴下，计时停止 | — | 趴下(4) | 计3帧→DONE |

★ 高风险新写环节 = C/D/E（角落倒顶 + 转身）。F/G/H 完全复用上一版已验证的推球段。

**航点常量（绝对坐标，米；现场可微调）**：

```
START          ≈ (2.90, 13.50)   # 赛段5独木桥终点前50cm跳下落点
TOP_Y          = 14.85            # A 退出阈值；继续贴墙后中心≈14.95(距顶墙0.15m)、下缘≈14.80>球顶14.60
CORNER_X       = 0.20             # B 退出：狗中心到此即到左上角（左墙x=-0.10挡停）
HDG_UP         = 90               # A 朝向：+y 上行
HDG_LEFT       = 180              # B 朝向：-x 左行
HDG_HEAD_IN    = 148             # C 目标头朝向：扎进左上角（尾朝328°对准缺口）
HDG_PUSH       = 328              # E/F/G 头朝向：球→缺口→圈心方向（atan2(-1.65,2.65)）
NUDGE_EXIT_X   = 0.35             # D 退出：狗中心x（后体已扫过球0.50、球被顶离角）
BALL0          = (0.50, 14.50)    # 球初始中心
KICK_TRIGGER_X = 2.40             # F→G：狗到此x改快步态
GAP_X          = 2.90             # 缺口边界
FINISH_CX      = 3.15             # 圈心x（狗最终停靠）
FINISH_CY      = 12.85            # 圈心y
FINISH_R       = 0.25
XY_TOL         = 0.08             # 航点到达容差
HDG_TOL_SLOW   = 8                # 朝向慢调阈值（°）
HDG_TOL_FAST   = 20               # 朝向快调阈值（°）
```

**两面墙自定位（A/B 的核心价值）**：A 段贴右墙上行、B 段贴顶墙左行，到角时
x 被左墙、y 被顶墙钉死。狗中心走在 y≈14.95（距顶墙0.15m），机身下缘 y≈14.80 >
球上缘 14.60，从球上方约 0.2m 掠过不碰球。到角靠撞墙定位，不依赖精确里程计。

**头进角 / 尾顶球（C/D 的核心）**：C 段从 180° 转到 148°（头扎进空角，只转32°），
此时尾朝 328°（对准缺口方向）。D 段后退步态=朝尾(328°)平移，后体扫过球把球沿
328° 顺出角落。E 段在球下方开阔区原地转180°，头从148°转到328°正对球。

**带球方向控制（F/G 核心，复用上一版）**：不做横向纠偏，始终把机身朝向锁定 328°。
朝向锁定后狗沿机头方向直推，球被机身/前腿带着沿 328° 直线滚向缺口。朝向漂移时先
用转向步态拉回 328° 再推（与赛段5 `_walk` 同构：先对朝向、对准后才走）。

## 状态机

```
A_GO_TOP        上行：转90°贴右墙向上，到 y≥14.85
B_GO_CORNER     左行：转180°贴顶墙向左到左上角，到 x≤0.20（左墙挡停，自定位）
C_AIM_TAIL      转尾对准★：从180°转到头朝148°（尾朝328°对准缺口）
D_NUDGE         倒退顺球★：后退步态(26)让后体扫过球，把球沿328°顶出角落，到 x≥0.35
E_FACE_PUSH     转身★：原地转180°，头从148°转到328°正对被顶出的球
F_DRIBBLE       带球：锁328°低重心前推(43)，把球带到缺口前（狗到 x≥2.40）
G_THROUGH_GAP   穿缝：换快前进(28)把球送过 x=2.90，狗随球到圈心 x≥3.15
H_LAYDOWN       圈内趴下，计3帧后置 DONE
DONE            返回 -1
```

状态转移与赛段5同构：每帧读 `position/gait_mode/rpy`，
`(gait==0&&mode==0)||(gait==1&&mode==9)||mode==7` 时返回 0 等待动作完成，避免重复
发指令打断步态。**H_LAYDOWN / DONE 例外**：故意绕过该等待判据——H 让趴下帧计数
确定性推进到 DONE（否则 G_LAY 发出后 mode 变7会被锁死、计数卡在1、趴下↔站立抖动）；
DONE 须无条件返回 −1（否则趴下中 mode==7 会把 −1 拦成 G_STAND，赛段永不报完成）。

## 视觉钩子（预留，默认关闭）

`detect_ball(frame)`：识别相机帧中足球，返回球相对机身的横向偏移（像素，正=偏右）。

- 默认主控传 `frame=None`，函数直接返回 0.0，控制走纯里程计——确定性优先。
- 现场若发现 D 段倒退顺球总偏，可接入 HSV+圆检测返回真实偏移，由 C/D 据此微调，
  **不改 `segment6_control` 签名**（与赛段1 `detect_yellow_line_offset` 一致）。

## 错误处理与边界

- **越界保护**：A/B 段靠航点阈值（y≥14.85 / x≤0.20）停，不主动顶墙；若 odometry
  显示已触 x≤−0.10 或 y≥15.10，当前移动步态退化为站立等待，不强行顶墙（墙可触碰
  不可越）。
- **朝向漂移**：所有「先对朝向后走」的阶段沿用 `_walk` 同构——偏差超 8° 慢转、超
  20° 快转，对准后才前进/后退。
- **D 段顶球失败兜底**：纯里程计无法直接感知球是否被顶出。D 设里程上限 x≥0.35 必
  退出，靠 E 转身 + F 前推补救；现场可开 `detect_ball` 判断球是否在身前。
- **E 段转身蹭墙**：转身位在球下方开阔区（D 已带狗到 x≥0.35），有转身余量；墙可
  触碰，蹭到无妨。转向方向选朝开阔侧扫以减少蹭墙。
- **狗未完全进圈**：G 段不留 −XY_TOL 余量，要求狗中心到达 FINISH_CX=3.15，确保后脚
  也越过缺口 x=2.90 落进圈内（圈仅50cm，零余量）。
- **趴下打断**：H 阶段绕过等待判据，趴稳计 3 帧再置 DONE。

## 风险与退路

| 风险 | 触发 | 退路 |
|------|------|------|
| D 段后体倒退顶不到球 / 顶歪方向 | 球未沿328°出角、仍卡角内 | 开 `detect_ball` 视觉校正；或微调 C 段头朝向 / D 段后退档(26→6) |
| 贴墙到角时蹭到球 | 顶墙距不足、狗下缘碰球 | 提高 TOP_Y（中心更贴墙）；或 B 段提前停 x |
| 带球途中球偏离328°直线 | 朝向漂移 / 地面不平 | 锁朝向纠偏；开视觉补横向偏移 |
| 球卡缺口边沿不进圈 | 球速不足 / 对位偏 | G 段快前进补推；必要时狗进圈后回身轻顶 |

**首要退路是踢球（模块开关 `USE_KICK_FALLBACK`）**：若 D 段反复顶不到球/顶歪，整段
降级为「角落外（或球右下开阔点）对准 328° → 快步态一脚踢射 → 追球进圈 → 趴下」，
复用 E 之后的朝向/步态/状态骨架，去掉 C/D 倒退环节。

## 测试

无单元测试惯例的硬件/仿真项目，逻辑用纯函数单测，运动验证靠 `test6.py` + Gazebo。

**纯逻辑单测**（无硬件，纯 Python）：覆盖 `_norm/_turn_step/_walk/_arrived`，A→H
每阶段的推进与选步，D 倒顶退出、E 转身分支、踢球退路分支。

**Gazebo 分阶段验证（风险从高到低）**：每步先纯里程计（`USE_KICK_FALLBACK=False`、
`detect_ball` 传 None），偏了再开视觉/退路。

1. **A/B 贴墙到角自定位（先验，最稳）**：摆位 (2.9,13.5)，跑到狗贴顶墙、左墙停在
   左上角。观察：上行/左行是否蹭球（应从球上方0.2m掠过）。
2. **C/D 倒顶顺球出角（最高风险，重点单验）**：到角后转头到148°、后退把球沿328°

   趴下，确认 `num==-1` 后兜底趴下(4)生效、计时停止。
5. **全程串跑**：(2.9,13.5) 一气跑到圈内趴下。
